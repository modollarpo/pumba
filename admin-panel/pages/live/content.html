MediaMTX Configuration
For more information on how to install and configure the self-hosted MediaMTX server, please visit the MediaMTX repository.
Base URL of the MediaMTX HLS server. Example: http://your-server-ip:8888
Base URL of the MediaMTX WHIP (WebRTC) ingest server. Example: http://your-server-ip:8889
Optional RTMP relay URL for external encoders such as OBS. Example: rtmp://your-server-ip:1935
Local folder where MediaMTX stores recorded streams (recordPath). Must be readable by this script on the same server. Example: ./recordings
